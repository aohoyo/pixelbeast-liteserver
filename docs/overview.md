# 项目概述

## 像素兽 (PixelBeast)

**小而强悍，无所不能** - 轻量级多站点服务器

### 项目定位

像素兽是一个面向个人开发者和小型团队的轻量级服务器解决方案，专注于：

- **简单易用** - 单文件部署，无需复杂配置
- **功能完整** - HTTP + FTP + SSL + 文件管理 + 系统监控
- **安全可靠** - AES-256-GCM 配置加密、安全入口、防暴力破解
- **高性能** - 内存占用 < 15MB，快速响应

### 核心功能

#### 1. 多站点管理

- 静态文件服务 + 反向代理
- 多域名绑定、独立端口
- 单个站点独立启停、重启
- 批量操作（启用、禁用、删除）

#### 2. FTP 服务

- 多用户管理、状态切换
- 容量限制、有效期控制
- 下载/上传限速、最大连接数
- 文件数量和单文件大小限制
- 实时状态同步

#### 3. SSL 证书

- Let's Encrypt 自动证书（规划中）
- 自定义证书上传
- 自动 HTTPS 重定向
- 证书到期提醒和自动续期

#### 4. 文件管理

- Web 文件浏览器
- 分块上传、断点续传
- 文件操作（复制、移动、重命名、删除、权限修改）
- 文件压缩（zip/tar.gz）和解压
- 文件分享（链接、过期时间、密码保护）
- 在线文件编辑

#### 5. 系统监控

- CPU 使用率（每核独立显示）
- 内存使用（含 Swap）
- 多磁盘分区监控
- 网络速率和流量统计
- 磁盘 I/O（速率、IOPS、延迟）
- 系统运行时长、进程统计

#### 6. Web 管理面板

- 现代暗色主题 UI（橙色强调色）
- 标签页组件化架构（BaseTab 模式）
- 系统监控仪表盘
- 三分类日志查看（Server/Auth/API + HTTP/FTP）
- 备份管理与恢复

### 技术特点

| 特点 | 说明 |
|------|------|
| 单文件部署 | 静态资源嵌入二进制，零外部依赖 |
| 配置加密 | AES-256-GCM 加密密码等敏感信息 |
| 最小依赖 | 优先使用标准库，仅 gopsutil 一个主要外部依赖 |
| 模块化设计 | 清晰的三层架构（协议层/业务层/基础层） |
| 前端组件化 | ES Modules + BaseTab 基类 + 依赖注入 |

### 适用场景

- 个人博客/网站托管
- 开发测试环境
- 小型团队内部服务
- 静态资源服务器
- 文件共享服务
- NAS 管理面板

### 版本历史

- **v3.1** - 日志系统重构、站点增量管理、系统监控增强
- **v3.0** - 配置系统重构、前端组件化、系统监控仪表盘
- **v2.0** - 多站点支持、FTP 服务、SSL 证书管理
- **v1.0** - HTTP 静态服务、Web 管理面板

### 快速开始

```bash
# 编译
go build -o pixelbeast

# 运行
./pixelbeast -config ./config

# 访问管理面板
# http://nas.banayou.com:9527/admin
# 默认账号: admin / admin123
```
