# 架构设计

## 整体架构

像素兽采用**两层架构**设计：

```
┌─────────────────────────────────────────┐
│           客户端层                       │
│  HTTP请求 | FTP客户端 | Web管理界面       │
└─────────────────────────────────────────┘
                    │
┌─────────────────────────────────────────┐
│           协议层 (handlers/)             │
│  ┌─────────┬─────────┬──────────────┐   │
│  │ HTTP    │  FTP    │   Admin      │   │
│  │ Server  │ Server  │   Panel      │   │
│  └─────────┴─────────┴──────────────┘   │
└─────────────────────────────────────────┘
                    │
┌─────────────────────────────────────────┐
│        业务逻辑层 (services/)            │
│  文件管理 | 用户管理 | 日志系统          │
└─────────────────────────────────────────┘
```

## 模块说明

### handlers/ - 协议层

负责处理 HTTP 和 FTP 协议请求：

| 文件 | 职责 |
|------|------|
| `server.go` | 服务器管理器，协调各服务启动/停止 |
| `http.go` | HTTP 静态文件服务 |
| `ftp.go` | FTP 服务器实现 |
| `vhost.go` | 虚拟主机支持 |
| `proxy.go` | 反向代理功能 |
| `ssl.go` | SSL/TLS 支持 |
| `filemanager.go` | 文件管理操作 |
| `logger.go` | 日志系统 |
| `system.go` | 系统监控（内存、协程） |
| `embed.go` | 静态资源嵌入 |

### admin/ - 管理面板

处理 Web 管理界面的所有请求：

| 文件 | 职责 |
|------|------|
| `handler.go` | 路由、认证、会话管理 |
| `response.go` | 统一响应格式 |
| `api.go` | API 端点实现 |
| `files.go` | 文件管理 API |
| `ftp.go` | FTP 管理 API |
| `sites.go` | 站点管理 API |
| `static.go` | 静态资源服务 |

### static/admin/ - Web 管理界面

前端资源，通过 Go embed 嵌入到二进制文件：

```
src/static/admin/
├── index.html         # 主面板（静态包含所有标签页）
├── login.html         # 登录页
├── css/               # 样式文件
├── js/                # JavaScript 模块
│   ├── core/          # 核心模块（状态、API、事件）
│   ├── ui/            # UI 组件
│   └── tabs/          # 标签页逻辑
└── images/            # 图片资源
```

## 设计原则

### 1. 最小依赖

优先使用 Go 标准库，减少外部依赖。

### 2. 嵌入一切

管理界面必须嵌入到二进制文件中，实现单文件部署。

### 3. 原生 Web UI

前端不使用框架，纯 HTML/CSS/JavaScript。

### 4. 低资源占用

保持内存占用低于 15MB。

### 5. 自包含

下载即可运行，无需额外安装。

## 数据流

### HTTP 请求流程

```
HTTP Request
    │
    ▼
handlers.HTTPServer
    │
    ▼
┌───────────────┐
│ 静态文件?      │──Yes──▶ FileServer
└───────────────┘
    │ No
    ▼
┌───────────────┐
│ 虚拟主机?      │──Yes──▶ VHostHandler
└───────────────┘
    │ No
    ▼
┌───────────────┐
│ 反向代理?      │──Yes──▶ ProxyHandler
└───────────────┘
    │ No
    ▼
404 Not Found
```

### 管理面板请求流程

```
/admin/* Request
    │
    ▼
admin.Handler.ServeHTTP
    │
    ├─▶ /login       ──▶ 登录页面
    ├─▶ /css/*       ──▶ 样式文件
    ├─▶ /js/*        ──▶ JavaScript
    ├─▶ /components/* ──▶ 组件文件
    │
    ├─▶ 认证检查
    │       │
    │       ▼
    │   ┌───────────────┐
    │   │ 已认证?       │
    │   └───────────────┘
    │       │ Yes
    │       ▼
    ├─▶ /api/*       ──▶ API 端点
    ├─▶ /*           ──▶ 主页面
    │
    └─▶ 未认证 ──▶ 重定向到 /login
```

## 会话管理

### 认证流程

```
用户登录
    │
    ▼
POST /admin/api/login
    │
    ▼
验证用户名密码
    │
    ▼
┌───────────────────┐
│ 认证成功?          │
└───────────────────┘
    │ Yes
    ▼
创建 Session
    │
    ▼
生成 CSRF Token
    │
    ▼
返回成功 + 设置 Cookie
```

### 安全机制

| 机制 | 参数 | 作用 |
|------|------|------|
| 会话超时 | 24小时 | 自动过期 |
| 登录限制 | 5次/15分钟 | 防暴力破解 |
| CSRF Token | 2小时 | 防跨站请求 |
| HttpOnly Cookie | - | 防XSS窃取 |
| SameSite Cookie | - | 防CSRF攻击 |
