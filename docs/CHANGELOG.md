# 更新日志

本文档记录项目的重大变更和新功能。

## [3.1.12] - 2026-04-13

### 修复

- **站点管理死锁**: 修复站点保存/删除/批量操作卡死的死锁问题（RWMutex 读写锁冲突）
- **SSL 证书申请超时**: 所有 Obtain/Renew 调用添加 5 分钟超时保护，防止无限等待
- **HTTP-01 Provider 空操作**: 替换无效的 HTTP Provider，改用 selfHostProvider 通过管理面板托管验证
- **证书部署不生效**: 部署证书后自动重启站点服务加载新证书
- **证书列表重复**: 按证书文件路径去重，共享同一证书的多个域名只显示一次

### 优化

- **DNS 自动申请回调**: DNS API 模式获取证书成功后自动持久化站点 SSL 配置
- **文件验证异步化**: 文件验证完成请求改为异步执行，避免 HTTP 请求超时
- **站点操作去重**: 站点启停/服务控制等 handler 提取公共方法减少重复代码
- **部署后站点刷新**: 证书部署后清除站点缓存，切页即见最新 SSL 状态

---

## [3.1.11] - 2026-04-12

### 新增

- **SSL 证书系统重构**: Let's Encrypt 自动证书申请（autocert + lego 双引擎），支持 HTTP/DNS/文件三种验证方式，步骤式申请流程（实时日志），DNS 服务商管理（阿里云/腾讯云/宝塔），自定义证书上传
- **开机自启服务管理**: 设置页新增服务管理标签页，支持 systemd/Windows 服务注册与检测
- **站点 SSL 配置**: 站点编辑表单新增 SSL 配置区域（证书模式、邮箱、强制 HTTPS）

### 优化

- **系统清理增强**: 支持选择性清理，新增回收站、npm/pip 缓存、崩溃转储、缩略图缓存等清理项，Windows 管理员权限检测
- **运行时间双显示**: 区分服务运行时间和系统运行时间，前端实时秒级计时器
- **Windows 系统信息**: 使用 gopsutil 替代 cmd 命令获取系统信息，平台相关代码拆分为独立文件

## 版本号规则

遵循语义化版本 (Semantic Versioning)：

- **MAJOR**: 不兼容的 API 变更
- **MINOR**: 向后兼容的功能新增
- **PATCH**: 向后兼容的问题修复
