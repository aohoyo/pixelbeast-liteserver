## [3.1.0] - 2026-04-03

### 新增

- **系统监控增强**: 多磁盘分区展示、每核 CPU 使用率柱状图、活跃进程数统计，CPU 采样改为后台 goroutine 不阻塞 API
- **FTP 用户限制**: 下载/上传限速、最大连接数、文件数量和单文件大小限制；登录时校验过期时间和连接数；实时检查用户启用状态
- **站点独立启停**: 单个站点启动/停止/重启 API 及前端按钮
- **备份下载恢复**: 备份列表增加下载和恢复按钮，备份创建支持多目录打包（config + sites + ftp）
- **FTP 根目录跳转**: 用户列表中根目录可点击跳转文件管理器
- **文件分享管理**: 文件分享链接、过期时间、密码保护
- **Windows 快捷目录**: 文件管理器支持 Windows 系统快捷导航
- **NTP 时间同步**: 系统时间同步功能
- **服务器名称可配置**: 登录页和管理面板标题动态显示
- **时区配置**: 支持选择服务器时区
- **站点表单**: 增加首页文件和目录浏览配置项

### 修改

- **配置结构重构**: 管理面板字段归入嵌套 `AdminConfig`；站点目录自动按 `SitesDir/siteID` 派生，移除 `Root` 字段
- **配置 API 简化**: 改用 JSON 反序列化直接映射 `ServerConfig`，替代手动字段解析
- **设置表单 data-path 绑定**: 表单元素统一使用 `data-path` 属性，自动填充和收集配置
- **FTP 状态独立 API**: 从设置页移至 FTP 页管理，服务状态页独立获取
- **前端精简**: 合并设置页面、删除 FTP 服务子标签
- **开发脚本精简**: `dev.sh` 和 `.air.toml` 去除冗余输出

### 优化

- favicon 和 logo 替换为 PNG 格式
- 默认 HTTP 端口从 3080 改为 3380
- FTP 用户批量操作和状态切换后立即同步到运行中的 FTP 服务器
- 备份列表改为切换标签时延迟加载

## [3.0.0] - 2026-03-27

### 重大变更

- **配置系统 v2**: 敏感信息加密存储
  - Admin 密码、FTP 用户密码使用 AES-256-GCM 加密
  - 自动生成 `secrets.key` 加密密钥
  - 权限 600，不在 web 目录下

- **前端架构**: 组件化 + 模块化
  - 标签页组件存储为独立 HTML 文件
  - 通过 `loader.js` 动态加载组件
  - BaseTab 基类统一生命周期管理
  - 依赖注入模式

- **安全入口**: 支持自定义管理面板路径
  - 默认 `/admin`，可自定义如 `/my-admin-portal`
  - 隐藏后台存在，提升安全性

### 新增

- **系统监控**: 宝塔风格仪表盘
  - CPU、内存、硬盘、负载环形图
  - 悬停显示详细信息
  - 一键释放内存、系统清理

- **分享功能**: 文件分享链接
  - 支持设置过期时间、密码保护
  - 分享链接管理

- **文档系统**: 完整的 docs/ 目录
  - `overview.md` - 项目概述
  - `architecture.md` - 架构设计
  - `api.md` - API 文档
  - `frontend.md` - 前端开发指南
  - `coding-standards.md` - 代码规范
  - `deployment.md` - 部署指南

- **工具模块**: `core/utils.js` 通用工具函数
- **骨架屏**: 加载状态骨架屏组件

### 优化

- **CSS 重构**: 减少 31% 重复代码
  - CSS 变量系统完善
  - 组件化 CSS 结构
  - 橙色暗色主题

- **JS 模块化**: BaseTab 基类模式
  - 统一依赖注入
  - 统一生命周期管理
  - 单例模式

### 修复

- 修复 `ftp.js` 和 `cert.js` 中的依赖访问问题
- 修复组件加载路径问题
- 修复密码验证时区问题
