# 更新日志

本文档记录项目的重大变更和新功能。

## [3.0.0] - 2026-03-27

### 重大变更

- **配置系统 v2**: 敏感信息加密存储
  - Admin 密码、FTP 用户密码使用 AES-256-GCM 加密
  - 自动生成 `secrets.key` 加密密钥
  - 权限 600，不在 web 目录下

- **前端架构**: 组件化 + 模块化
  - 标签页组件存储为独立 HTML 文件
  - 通过 `loader.js` 动态加载组件
  - BaseTab 基类统一生命周期管理
  - 依赖注入模式

- **安全入口**: 支持自定义管理面板路径
  - 默认 `/admin`，可自定义如 `/my-admin-portal`
  - 隐藏后台存在，提升安全性

### 新增

- **系统监控**: 宝塔风格仪表盘
  - CPU、内存、硬盘、负载环形图
  - 悬停显示详细信息
  - 一键释放内存、系统清理

- **分享功能**: 文件分享链接
  - 支持设置过期时间、密码保护
  - 分享链接管理

- **文档系统**: 完整的 docs/ 目录
  - `overview.md` - 项目概述
  - `architecture.md` - 架构设计
  - `api.md` - API 文档
  - `frontend.md` - 前端开发指南
  - `coding-standards.md` - 代码规范
  - `deployment.md` - 部署指南

- **工具模块**: `core/utils.js` 通用工具函数
- **骨架屏**: 加载状态骨架屏组件

### 优化

- **CSS 重构**: 减少 31% 重复代码
  - CSS 变量系统完善
  - 组件化 CSS 结构
  - 橙色暗色主题

- **JS 模块化**: BaseTab 基类模式
  - 统一依赖注入
  - 统一生命周期管理
  - 单例模式

### 修复

- 修复 `ftp.js` 和 `cert.js` 中的依赖访问问题
- 修复组件加载路径问题
- 修复密码验证时区问题

## 版本号规则

遵循语义化版本 (Semantic Versioning)：

- **MAJOR**: 不兼容的 API 变更
- **MINOR**: 向后兼容的功能新增
- **PATCH**: 向后兼容的问题修复
